# basic building blocks
three kinds of entities :
- concepts (set of individuals)(unary predicates)
- roles (binary relations between individuals)
- individual names ( constants )

It contains a set of statements, called Axioms. They describe partial knowldge of the world

## ABox axioms
capture knowledge about named individuals using concept assertions and role assertions

## TBox axioms
describe relationship between concepts.
